# 网站与推广长期规则

canonical owner：浏览、移动端、订阅及推广。

## 1. 浏览职责

- U-01 [HARD]：首页负责最新正式期次入口，栏目负责主题发现，归档负责日期回溯，搜索负责正式内容检索。DEMO 隔离遵守 P-13。
- U-02 [HARD]：保留搜索和移动端可用性。窄屏使用可点击的标准折叠菜单，不缩字到难读，不强制横向滚动，不依赖 hover 或空格拼接。
- U-03 [HARD]：保留 Task 07 确认的导航语义：品牌链接首页，推文、论文、新方法、会议征稿、往期，以及 GitHub、官网、课程、搜索。GitHub 黑色图标位于官网左侧，链接公开仓库并具备可读名称、键盘焦点和新窗口安全属性。栏目索引不重复占一级导航，软件 / 方法 / 领域是叠加元数据，不复活旧群组固定栏目。
- U-04 [HARD]：内部标识为 `lianxh-new`、`research-frontier`、`methods-tools`、`academic-updates`；software / methods / fields 为可空列表；推文 tags 保持 2–3 个，其他类型按依据设置。外站入口新窗口打开并用 `rel="noopener noreferrer"`；每页保留链接官网的 lianxh.cn 页脚。
- U-05 [DEFAULT]：延续品牌、响应式 Quarto 和稳定条目锚点；资产兼容 /brief/ 子路径，不硬编码根路径 /assets/。具体布局由 Task 09 在规则内设计，历史像素值不升格为 HARD。

## 2. 课程与推广

- U-06 [HARD]：课程、公开课、助教招聘由网站承担，不进微信正文。长期采用“公开来源 → 自动发现 → 结构化配置 → UI renderer”，不靠每次开课手改 HTML。
- U-07 [HARD]：`https://www.lianxh.cn/blogs/44.html` 为课程自动发现主来源之一，优先识别当前课程 / 新课；`https://www.lianxh.cn/KC.html` 可作综合入口，不是唯一数据源。
- U-08 [HARD]：公开课 / 助教招聘抓取不确定时不强行展示；稳定自动识别方案为 [PENDING]。实现归 Task 09，ALL-01 不实现悬浮窗或采集。
- U-09 [DEPRECATED]：固定 KC HTML Callout 作为长期唯一课程数据方案。现有入口本次保留，不认定配置驱动已完成。

## 3. 订阅

U-10 [HARD]：暂缓完整邮件订阅。Task 09 可预留入口或扩展位置，不自行引入账户、邮件数据库、第三方邮件平台或隐私数据收集。完整邮件订阅启用时点与方案为 [PENDING]。

U-11 [HARD]：日常正文使用“本期重点”“延伸阅读”；少量内容也保留两部分及原因说明。历史集合页首展示分类数量与入口，类别涵盖推文、论文、命令/软件、会议。正式历史条目可从栏目和搜索找到；同一成果不重复计数，历史入口不称为“查看本期”。

U-12 [HARD]：四个栏目页每页最多 10 条，采用独立静态分页，首屏不预载其他页正文。首页最新期次显示最近 3 个正式发布日期；四个栏目框仅保留名称。跨页关键词检索使用顶部全站搜索，不提供容易误认为全站搜索的单页筛选框。

U-13 [DEFAULT]：“本期重点”“延伸阅读”两个主标题统一墨绿色，与条目类别标题区分。首页最新期次标题上方间距在本轮原值基础上增加 50%。课程推广桌面保留海报，窄屏使用同一已审核课程实体生成可读文字卡片，展示标题、完整授课日期及详情入口；不将海报整体缩小作为手机端唯一展示。

U-14 [HARD]：所有正式期次的网页正文标题、首页入口、往期入口和搜索中的期次名称统一为 `连享会 · 快讯 | YYYY.MM.DD`，由同一个日期格式函数生成，不直接使用历史数据的旧 title。旧发布快照和微信发送证据不因此重写；DEMO 保持隔离。

U-15 [HARD]：往期不沿用栏目每页 10 条限制，采用年份、月份两级原生折叠，月份内列出该月所有正式期次，按日期倒序，不拆开月份。[DEFAULT] 每页一个完整年份，年份默认展开；全站归档不超过 31 期且只有一个年份时，月份默认展开，超过此量或跨年时月份默认收起；跨年才分页，导航显示年份，只有一页时不显示页码。顶部只保留简短浏览提示，数量放在年/月摘要中。

U-16 [HARD]：日常正文、历史集合、栏目卡片和标签概览中的标签提供可点击的站内检索入口。当前采用 Quarto 全站关键词搜索，不冒称精确标签筛选；链接正确编码中文和特殊字符，兼容本地和 /brief/ 子路径，并具备键盘焦点。
