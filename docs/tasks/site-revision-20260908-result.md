## 4. 规则与构建入口

长期要求分别写入现有 `content-rules.md`、`architecture.md`、`ui-rules.md`、`automation-rules.md`，由 `decision-log.md` 的 D-20260908-02 记录裁定。本报告只记录完成证据，不另立规则。

```powershell
& $env:PYTHON_EXE scripts/build_website.py
& $env:PYTHON_EXE scripts/build_website.py --check
quarto render
```

`build_website.py` 先检查共同事实、原短版和历史引用，再生成日期页、历史页及栏目页。CI 的 `--check` 拒绝已过期的生成文件。Quarto 构建前也执行同一入口；构建后检查搜索、内部链接及草稿隔离。
