# 每日工作日志与固定清单

每次自动运行先核对目标日期及已有证据，维护 `ops-local/runs/YYYY-MM-DD/daily-work-log.md`。该私有日志记录共享路径和运行细节，不提交。

1. 网站与微信：沿用现有采编、核验、构建、发布及共享 TXT 检查。
2. 微博：当天完整文稿、来源与方法边界复核，保存 `weibo/YYYYMMDD.md`，核对交付字节。
3. 知乎：当天文章、结构、引文、原始链接复核，保存 `zhihu/YYYYMMDD.md`，核对交付字节。
4. 小红书：精选当期研究和工具，保存 `xiaohongshu/YYYYMMDD/` 的正文、封面、内容卡片、卡片文本、选稿与编辑来源。核对每张图片无截断、正文与来源一致，再核对共享副本字节。
5. 分别记载生成、复核、交付、文件数、哈希、异常和下一步。已交付文件不等于已在平台发布。

## 制作环境与审核边界

三平台入口 `scripts/build_social.py` 生成的是初稿：微博、知乎逐项保留真实来源日期与发表状态或软件版本；小红书记录实际选稿构成，不把不足3篇论文的期次写成固定3篇。生成后仍须全文复核、逐张查看图片并校验共享副本。脚本不登录平台、不自动发布。

图卡制作依赖 Python 的 Pillow 和 Windows 微软雅黑字体（常规与粗体）。新电脑须重新解析 Python 路径并核对字体与依赖，不能直接沿用旧电脑的绝对解释器路径。每日输出使用未占用的私有暂存目录，勿覆盖已交付的不同内容。
